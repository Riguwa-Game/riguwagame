# ink-monitor

One small Node process doing two jobs for Inkstake Arena. Stack is **viem**; see the exception below.

## 1. Run monitor (WebSocket, port 8920)

Watches a solo run live and signs its outcome.

- Accepts a socket only for a `runId` that is `Active` on-chain and owned by the claimed player.
- Receives compact run events — wave started, enemy killed, damage taken, player died. Never 60 Hz
  state; bandwidth is negligible by design.
- Rejects skipped waves, impossibly fast clears, kills beyond what the wave could spawn, and deaths
  claimed above the wave actually reached.
- On run end, signs an EIP-712 `RunResult` **and submits `settleRun` itself**. The player already
  signed to stake; asking them to sign again to *receive* their payout is a poor trade, and a
  declined signature used to leave the stake sitting until the TTL. If the monitor's own submission
  fails it hands the signature and the result to the client, which submits as a fallback rather
  than stranding the stake.

### Why wave checks are bounds, not a replay

An earlier design replayed the game's seeded RNG stream to derive exact wave composition. That was
abandoned: `startWave` draws from the same stream for the modifier, every enemy, the flavour
message, seven pickup positions and a jitter per pickup — and enemy spawning draws more still. Any
change to the game shifts the stream and the monitor would start rejecting honest runs.

`src/monitor/waves.ts` computes an **upper bound** instead, which needs no RNG: the only random
input to wave size is whether SWARM rolled, so assuming it always did gives a sound ceiling. That
is what a plausibility check actually needs — nobody can kill more enemies than could spawn.

`src/monitor/prng.ts` still mirrors the game's PRNG exactly, and `test/prng.test.ts` guards it with
a vector generated by the **game's own** `prng.js`.

## 2. Attestcoin relayer

Watches `DoodleGate` on Sepolia; for each event: wait for the block to be attested on Creditcoin,
fetch Merkle and continuity proofs from the Proof Builder, submit to `DoodleGateASC.execute`.

This is what makes cross-chain entry **gasless** — the player never needs tCTC.

### Two things that will bite you

**Attestation lag is 20–40 minutes.** Measured on CC3 testnet. The SDK's default
`waitUntilHeightAttested` timeout is far shorter, and a timeout means a paid entry is silently
dropped. `config.attestWaitMs` defaults to an hour. Use `npm run relay -- <txHash>` to recover a
transaction whose relay timed out.

**The monitor wallet needs tCTC.** It submits the relay transaction AND every settlement. A fresh
attestor key has zero balance and every submission fails with `gas required exceeds allowance 0`.
Fund it, and watch it — if it empties, settlement falls back to asking the player to sign.

## The ethers exception

Everything here is viem **except** `src/relayer/index.ts`. The official `@gluwa/usc-sdk` is
ethers-based: `PrecompileChainInfoProvider` and `ProofBuilder` both take an ethers provider. Using
the official SDK is worth more than stack purity, so ethers is scoped to that one file.

The provider cast there works around a TypeScript nominal-privates quirk. Runtime correctness is
proven by `npm run check:attestcoin`, which drives that exact provider against the live precompile.

## Hard rules

- **The monitor key is an attestor key, never an owner key.** It signs run results and submits
  proofs. It holds no admin rights. If it leaks, the owner rotates it with
  `escrow.setAttestor(old,false)` then `escrow.setAttestor(new,true)`.
- **Never commit `.env`.**
- `src/monitor/prng.ts` must stay behaviourally identical to `game/doodleshooter/src/prng.js`.
- The monitor is Phase 1 scaffolding. Phase 2 replaces it with peer quorum by reconfiguring
  `setAttestor` / `setThreshold` — no contract change. See the root `CLAUDE.md`.

## Commands

```bash
npm install
npm test                    # 35 tests, node --test
npm run typecheck
npm run dev                 # monitor + relayer
npm run check:attestcoin    # prove the SDK reaches the live precompile
npm run relay -- <txHash>   # relay one already-paid Sepolia transaction
```

## Production

Runs on the VPS behind nginx as `wss://monitor.riguwa.xyz` (TLS terminated by nginx, proxied to
`127.0.0.1:8920`). That box also hosts unrelated projects — **only ever add an nginx server block
and a systemd unit; never edit the existing ones.** See `docs/DEPLOYMENT.md`.
